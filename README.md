# 🪑 Les meubles de PH

> Une seconde vie pour des meubles comme neufs.

---

## 🎯 Objectif du projet

Créer un site web élégant permettant de présenter et vendre les meubles de notre fils suite à son déménagement.

Le site doit inspirer confiance, mettre en valeur les meubles grâce aux photos et être très simple à mettre à jour.

Le visiteur doit avoir l'impression de parcourir une boutique de mobilier plutôt qu'une simple liste d'annonces.

---

# Public visé

- Famille
- Amis
- Connaissances
- Acheteurs potentiels

Le site doit être compréhensible par tous, aussi bien sur ordinateur que sur smartphone.

---

# Les objectifs

✅ Mettre les meubles en valeur

✅ Afficher plusieurs photos

✅ Donner envie de cliquer

✅ Pouvoir marquer un meuble comme vendu

# Source des données

Le fichier Excel est la référence.

Il contient :

- référence
- catégorie
- désignation
- description
- dimensions
- volume
- état
- date d'achat
- prix neuf
- prix de vente
- nombre de photos
- statut

Le site utilisera un fichier JSON généré à partir de ces données.

---

# Les photos

Toutes les photos sont en 800 × 600 px.

Convention :

001-01.jpeg
001-02.jpeg
001-03.jpeg

002-01.jpeg
002-02.jpeg

...

La photo "-01" est toujours la photo principale.
